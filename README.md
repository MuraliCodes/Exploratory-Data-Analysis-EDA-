# 🚢 Titanic Dataset - Exploratory Data Analysis (EDA)

This repository contains a complete **Exploratory Data Analysis (EDA)** of the Titanic dataset using Python and popular data science libraries.

## 📊 Overview

The Titanic dataset is one of the most well-know datasets for classification and survival analysis. In this project, we analyze:

-Survival patterns by gender, age, and class.
-Missing data outlier detection.
-Correlation between features.
-Trends and distributions using seaborn/matplotlib.

## 📁 Dataset

The dataset used is the **Titanic Dataset** provided by Kaggle:

-['Titanic-Dataset.csv']

## 🔧 Setup Instructions

You can run the analysis in **Google Colab** or locally with the following libraries:

pip install pandas, seaborn, matplotlib

📈 Visualizations Included

-Pairplot of numeric features by survial.

-Heatmap showing feature correlation.

-Histograms and Boxplots for age,fare,class.

-Count plots for survival by sex and class.


📌 Observations

-Females and younger passengers had a higher survival rate.

-Passengers in 1st were more likely to survive.

-Age and Fare distributions are skewed.

-Missing values detected in 'Age' and 'Cabin'.
